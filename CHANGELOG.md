# Changelog

## 1.0.0 — 2026-10-10
First public release. Tested with Cyberpunk 2077 2.31.
- Gravity gun item (Igla base) with the Half-Life 2 RTX model, glow, sounds, name, description (en, ru) and an
  inventory icon at vanilla size.
- Pull, hold, launch and punt for physical props, NPCs (ragdolls) and vehicles, following Half-Life 2's physcannon.
- Keyboard bindings and a tuning window in the Cyber Engine Tweaks overlay.
